# Faith panel pictures (2026-11-24)

Taken in a Wars of Liberty 1.0.15c test copy with this pack applied, single player, British, Chinese and Mapuche
(WallMapu). The faith value shows resource 4 without the faith pack's DLL key, so before any gathering it is the
home city's unspent skill points; during the test the start food crates and one kind of tree held faith (a
temporary data edit, removed after), which is how the villagers gathered it.
